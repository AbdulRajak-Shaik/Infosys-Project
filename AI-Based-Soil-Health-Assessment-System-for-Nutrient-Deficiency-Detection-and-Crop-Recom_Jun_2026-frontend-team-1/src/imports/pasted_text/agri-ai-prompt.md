# **Master UI/UX Design Prompt for Figma AI / Google Stitch / Lovable**

---

## **Project Title**

**AI-Powered Smart Agriculture Recommendation System**

Design a **world-class, modern, premium, enterprise-level SaaS web application** for an AI-driven Agriculture Platform. The design should feel like a combination of **Vercel Dashboard + Linear + Notion + Stripe + Google AI Studio + Microsoft Fluent + Material 3**, while maintaining an agriculture-focused identity.

The UI should be extremely clean, spacious, intuitive, professional, and responsive.

The application will integrate with a **FastAPI backend**, use **JWT Authentication**, **Role-Based Access Control (Farmer, Researcher, Admin)**, **PostgreSQL**, **AI-powered prediction models**, **Weather APIs**, and a **Multilingual AI Chatbot**.

# Backend Integration Awareness

The UI should be designed to consume REST APIs exposed by a FastAPI backend using JWT authentication. Include role-aware navigation (Farmer, Researcher, Admin), authenticated route protection, prediction workflows, weather integration, multilingual chatbot support, and standardized success/error states for endpoints such as `/auth`, `/soil`, `/crop`, `/fertilizer`, `/disease`, `/chatbot`, `/weather`, `/history`, `/feedback`, and `/admin`. Design should anticipate loading, empty, error, and success states for every API-driven screen.
